## 小精灵页侧边栏冻结：会话列表不隐藏，上一个会话选中态保留（未提交）
- 需求（Nick）：选中小精灵后，不隐藏上一个会话的选中状态、以及会话列表——侧边栏保持进入小精灵前的样子。
- 难点：进 pixie 页会把活动工作区切到 workspace/pixie，且 app-store 会话目录被 pixie 会话快照重建（`upsertSessionSnapshot` 换 workspaceId 即整目录替换）——直接渲染 SessionList 会变成「小精灵会话列表」。必须冻结。
- 方案：**冻结快照**。
  1. 新增 `features/pixie/pixie-sidebar-snapshot.ts`（zustand）：`{ workspace, items, activeSessionId }`，PixiePage 挂载锚定时 capture（在 acquire 切工作区之前），卸载 clear。条目/工作区对象在 store 层均不可变替换，浅拷数组即安全。
  2. `SessionList` 新增 `frozen?: SessionListFrozenData` 模式：目录/选中/就绪门控/pinned/终端标记键全部改读快照；跳过 session.list 刷新、访问确认（acknowledgeVisited）、reveal 定位 effects；禁用全部会话 RPC（归档按钮隐藏、右键只剩 pin/复制路径，rename/delete/export 置灰）；点击行 = `openSessionAcrossWorkspaces({ cwd: 快照工作区, sessionPath, optimistic: false })` 后落 chat 页（先导航后 setPage，PixiePage 卸载恢复带非 pixie 守卫，不二次激活）；导航 failed 留在原地。
  3. `Sidebar.tsx`：pixie 分支渲染 frozen SessionList（无快照才空），新增 `usePixieSidebarSnapshot` 选择器。
- 测试：新增 `SessionList.frozen.dom.test.tsx` 5 例（快照渲染+选中态+pixie 目录不混入、点击导航+落 chat 页、点选中项同样导航、失败不切页、RPC 禁用）；Sidebar SSR pixie 用例只保留「新会话」可见断言——**zustand v5 在 renderToStaticMarkup 下只读模块加载时的初始快照，运行期 capture 不可见**（存量注释早有提醒），快照列表断言只能进 jsdom DOM 测试。
- 调试拾遗：会话名显示经 `clampSessionTitleForDisplay`（22 字符截断加 …），DOM 测试 getByText 用长名会不命中。
- 验证：desktop 全量 184 files / 1642 tests ✅；typecheck + eslint ✅。改动未 commit。

## 小精灵页「新会话」：侧边栏按钮不再隐藏，且作用于进入前的工作区（已提交 45d2155）
- 需求（Nick）：① 点击小精灵进入小精灵页后，侧边栏「新会话」按钮不要隐藏；② 该按钮的「新会话」作用于**进入小精灵之前的工作区**，不是 pixie 工作区。
- 根因：`Sidebar.tsx` 渲染条件 `page !== "pixie"` 直接藏掉了 NewSessionButton；且 PixiePage 挂载会把活动工作区切到 workspace/pixie，直接 `createNewSession` 会在 pixie 工作区里误建一条小精灵会话。
- 改动（apps/desktop，3 文件 + 2 测试）：
  1. 新增 `features/pixie/pixie-previous-workspace.ts`：模块级记录「进入小精灵前的工作区 canonicalCwd」（remember/get/clear + resetForTests），并导出 `createNewSessionFromPixiePage()`——目标 = 记录值，缺记录（冷启动直落 pixie）退回 `desktopSettings.lastWorkspace`（App 从不把 pixie 页持久化为最近位置，见 App.tsx persistRecentDesktopLocation 的 pixie 跳过）；`activateWorkspaceAcrossWorkspaces(target, { optimistic: false })` 阻塞切回（session.create 需 serviceGraphLock 释放，同备忘录执行路径约束）→ `setPage("chat")` → `createNewSession()`。blocked 静默放弃、failed 由激活路径自身报错；无目标时宁可 no-op 也不在 pixie 里建。
  2. `PixiePage.tsx`：挂载锚定记录 prevCwdRef 时同步 `rememberPixiePreviousWorkspace`；卸载清理 `clearPixiePreviousWorkspace`。PixiePage 自身恢复逻辑不变（仍用局部 ref；且其恢复守卫是"活动工作区还是 pixie 才恢复"，所以按钮先切回后卸载不会二次激活竞争）。
  3. `Sidebar.tsx`：去掉 NewSessionButton 的 `page !== "pixie"` 隐藏条件（telegram 视图仍隐藏）；onClick 分流——pixie 页走 `createNewSessionFromPixiePage()`，其余页面维持原路径（非 chat 先 setPage("chat") 再建）。
- 遗留注意：命令面板（`lib/commands/registry.ts`）的 create 命令未分流——在小精灵页用命令面板新建仍会建在 pixie 工作区；如需彻底一致，可让 registry 也走同一分支（本次未动，避免影响 PixieBackToCurrentButton 兜底等 createNewSession 既有调用方）。

## 提问卡（extension UI）标题对齐修复（未提交）
- 需求（Nick 截图）：① 展开态标题旁图标没上下居中；② 折叠态文字标题没上下居中；③ 展开/折叠箭头位置变了。
- 根因（`55ce658` 加 chips 行引入的回归）：
  1. 展开态 header 是 `flex items-start`，icon 与 chevron 带 `mt-0.5` → 被顶到第 1 行（chip 行），实测比标题行中心高 **23.5px**（icon cy 305.7 vs h2 cy 329.2）。
  2. 折叠态标题 `min-h-6 line-clamp-2`：单行文字在 1.5rem 高的盒子里顶到上沿，比行中心高 **3.5px**（根字号 14px 环境下 21px 盒 / 14px 行高）。
  3. chevron 所在 header 行带 `pr-7` → 展开态箭头比折叠态左移 **24.5px**（898.3/912.3 vs 922.8/936.8），且不在标题行上。
- 改动（apps/desktop，2 文件）：
  - `ExtensionUiRequestContent.tsx`：header 从单行 flex 改为 **两行 grid**（`grid-cols-[auto_minmax(0,1fr)_auto]`，canFold 时 3 列否则 2 列，`items-center` + `gap-x-2.5`）；chips 行 `col-start-2 row-start-1`，icon 与 chevron 均 `row-span-2 self-center`（**跨两行居中 → 在 chip 行+标题这整块头部里垂直居中**，最终版；中间试过 `row-start-2` 只对齐标题行，Nick 否掉："不要只对齐问题标题"），h2 直接作 grid item（去掉 `min-w-0 flex-1` 包裹层）；删除 icon/chevron 的 `mt-0.5` 与 inline header 的 `pr-7`。chips 仍与标题左缘对齐（x=89）。实测 icon/chevron cy == foldToggle cy（316.7，偏差 0.0）；`row-start-2` 版则比区块中心低 12.5px。
  - `InlineExtensionUiRequest.tsx`：折叠标题加一层 `flex min-h-6 items-center` 包裹，内层保留 `line-clamp-2` → 单行居中、两行仍正确截断（实测 clientHeight 28 < scrollHeight 42）。
- 验证方法（可复用）：临时用 vite 构建一个自包含页面渲染**真实组件**（`cardlab.tsx` + `cardlab.html` + `vite.cardlab.config.ts`），内联 CSS/JS（@font-face 只内联 <300KB 的小子集，几 MB 的 CJK 字体丢弃），经 CDP 以 `data:` URL 在无头 Edge 里渲染并 `getBoundingClientRect` 量取几何 + 截图。修复后 icon/chevron cy 与标题 cy 完全一致（329.2），箭头右缘与折叠态一致（936.8）。调试产物已删除，对比图留在 `.workbuddy/artifacts/card-title-alignment.png`。
  - 坑：`String.replace` 的替换串里 `$&`/`$'` 会被解释成模式，内联大段 JS 必须用函数式替换。
- 验证：`vitest run src/features/chat` 44 文件 / 475 用例全绿；改动文件 eslint ✅。`tsc --noEmit` 仅剩 `features/sessions/SessionList.tsx(142,14) WorkspaceSnapshot 未定义` —— **是另一个并发 agent 会话的在制品，与本改动无关，未触碰**（同仓并发时用「tsc 全量输出里筛自己的文件」来判定）。改动未 commit。
