# 问题现象

## 复现场景

用户在使用 PiAbyss 聊天界面时，间歇性出现以下 UI 显示异常：

## 具体表现

### 1. 用户气泡消失
- 用户发送新消息后，本应立即显示的**用户消息气泡没有出现**
- 输入框已清空，说明消息确实已发送
- 但对应的用户消息气泡在界面上完全不可见

### 2. 白色竖方块异常
- 上一条**已经结束**的 Agent 回复消息左下角出现了一个**白色竖状实心方块**
- 这个方块看起来像一个块状光标（█）
- 但该 Agent 消息早已完成，不应该还有流式光标

### 3. 持续异常
- 过一会儿 Agent 开始新的回复时，白色方块消失
- 但**用户发送的消息气泡仍然不显示**
- 消息实际上已经存在（因为 Agent 在回复它），但 UI 上就是看不到

### 4. 切换会话后恢复
- 切换到其他会话，再切回来
- 所有内容突然恢复正常
- **消失的用户气泡重新出现**，一切显示正确

## 影响范围

- **不是每个会话都会遇到**，只在特定条件下触发
- 触发后会影响用户体验，造成困惑
- 需要手动切换会话才能临时恢复
- 但下次发送消息时可能再次出现

## 关键线索

1. **间歇性发生** - 说明与会话的历史状态有关
2. **白色方块** - 提示流式状态判断错误
3. **切换会话恢复** - 说明是渲染层计算问题，而非数据丢失
4. **只影响部分会话** - 某些会话中存在触发条件的特殊数据
