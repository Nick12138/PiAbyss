## 一句话总结
custom_message 条目**无条件计数**（pi 的 session.messages 包含所有 custom 消息，
display 只控制渲染可见性）；不可投影的悬挂 message 条目不计数。

## 核心修复（transcript-model.ts 的 sourceMessages()）
```typescript
// 1. message 分支（5d60777，修复原“气泡消失”bug）：
//    仅当能投影出消息时才计数
if (message) {
  projectedMessageCount += 1;
  sources.push(...);
}

// 2. custom_message 分支（b9c8711，修复 d305598 引入的“尾部重复”回归）：
//    无条件计数 —— pi 运行时与恢复路径都让每条 custom_message
//    占据 session.messages 一个位置，display 只影响渲染
projectedMessageCount += 1;
sources.push(...);  // 隐藏 custom 仍 push source 以保持 assistant 轮次边界
```
