# Bug 修复核心要点（快速参考）

## 一句话总结
`custom_message` 的 `display:false` 条目被错误计数，导致用户气泡消失。

## 核心修复（3 行代码）
```typescript
// 文件：apps/desktop/src/features/chat/transcript-model.ts
// 位置：sourceMessages() 函数中的 custom_message 处理部分

// 修改前：
projectedMessageCount += 1;  // ❌ 无条件计数

// 修改后：
if (record.display === true) {  // ✅ 只有 display:true 才计数
  projectedMessageCount += 1;
}
```
